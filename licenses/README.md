# Bundled third-party license texts

Flyt release archives include this directory so recipients receive the legal
texts required for redistributed dependencies.

- `MIT.txt` applies to the MIT-licensed components identified in
  `../THIRD-PARTY-NOTICES.md`.
- `Apache-2.0.txt` applies to SQLitePCLRaw.
- The package build adds the resolved .NET runtime `LICENSE` and
  `THIRD-PARTY-NOTICES` files here with package-specific filenames.

The generated SPDX SBOM in each release archive remains the authoritative
inventory of exact package versions and files.
