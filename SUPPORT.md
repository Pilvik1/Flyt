# Support

Flyt is an early-stage open-source project maintained on a best-effort basis.

- Questions and usage problems: GitHub Discussions once enabled, otherwise an issue.
- Reproducible bugs: use the bug report template.
- Feature ideas: use the feature request template.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md).

Please redact usernames, absolute paths, provider session IDs, tokens, prompts,
and terminal output before sharing diagnostics. A screenshot is still a data leak
if the secret happens to be wearing a nice terminal theme.
